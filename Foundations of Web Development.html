1. HTML (HyperText Markup Language)

HTML is the standard markup language for creating web pages. It provides the structure and content of a website. Think of it as the skeleton of a webpage.

Key Concepts:

  • Elements: Building blocks of HTML, defined by tags (e.g., <div>, <p>, <h1>).
  • Tags: Keywords enclosed in angle brackets (<tag> and </tag>). Most elements have an opening and a closing tag.
  • Attributes: Provide additional information about HTML elements (e.g., <img src="image.jpg" alt="My Image">).
  • Document Structure: A basic HTML document includes <!DOCTYPE html>, <html>, <head> (for metadata), and <body> (for visible content).

Example:

<!DOCTYPE html>
<html lang="en">
<head>
<meta charset="UTF-8">
<title>My First HTML Page</title>
</head>
<body>
<h1>Hello World!</h1>
<p>This is a paragraph of text.</p>
<a href="https://www.example.com">Visit Example</a>
<img src="image.png" alt="Example Image" width="100">
</body>
</html>

2. CSS (Cascading Style Sheets)

CSS is used to style the presentation of your HTML content. It controls the layout, colors, fonts, and other visual aspects of a webpage.

Key Concepts:

  • Selectors: Target HTML elements you want to style (e.g., by tag name, class, ID).
  • Properties: Aspects of an element you can style (e.g., color, font-size, background-color).
  • Values: Settings for CSS properties (e.g., red, 16px, #f0f0f0).
  • Ways to Apply CSS:
    • Inline CSS: Directly within HTML elements using the style attribute (not recommended for large projects).
    • Internal CSS: Within <style> tags in the <head> section.
    • External CSS: In a separate .css file linked using the <link> tag (best practice).

Example:

/* styles.css */
body {
font-family: sans-serif;
background-color: #f0f0f0;
color: #333;
}
h1 {
color: blue;
text-align: center;
}
p {
font-size: 1.1em;
line-height: 1.5;
}

To use this external CSS, you would link it in the <head> of your HTML:

<head>
<link rel="stylesheet" href="styles.css">
</head>

3. JavaScript (JS)

JavaScript is a powerful scripting language that adds interactivity and dynamic behavior to web pages. It allows you to manipulate HTML and CSS, respond to user actions, and much more.

Key Concepts:

  • Variables: Used to store and manage data.
  • Data Types: Different kinds of values (e.g., numbers, strings, booleans).
  • Operators: Symbols used to perform operations on values (e.g., +, -, ==).
  • Functions: Blocks of reusable code.
  • Events: Actions that occur in the browser (e.g., clicks, mouseovers, form submissions).
  • DOM (Document Object Model): A programming interface for HTML and XML documents. JavaScript can use the DOM to access and modify the structure, style, and content of a webpage.

Example:

<button id="myButton">Click Me</button>

<script>
const button = document.getElementById('myButton');
button.addEventListener('click', function() {
alert('Button Clicked!');
});
</script>
